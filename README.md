#Descripción breve del sitio
Este proyecto consiste en un sitio web de promoción turística para la comuna ficticia Destino Cordillera. La plataforma presenta una propuesta visual y funcional para que los usuarios conozcan los principales atractivos del destino, incluyendo panoramas, alojamiento, gastronomía y opciones de reserva y contacto.

Objetivo del sitio
Promocionar turísticamente la comuna ficticia Destino Cordillera y facilitar la navegación por sus principales servicios y experiencias mediante una estructura web clara, visualmente atractiva y funcional.

Páginas principales
Inicio
Panoramas
Alojamiento y gastronomía
Reservas y contacto

Tecnologías utilizadas
HTML5
CSS3
Bootstrap 5
GitHub para control de versiones

Instrucciones para ejecutar y visualizar el sitio
Clona este repositorio:
git clone https://github.com/Korsohh/desarrollo-web-equipo-08.git

Ingresa a la carpeta del proyecto:
cd desarrollo-web-equipo-08

Abre el archivo index.html en un navegador para acceder al sitio.
